# BunkerG

Proyecto final del módulo de JavaScript. La web presenta una empresa ficticia dedicada al diseño de espacios gaming y de creación.

## Páginas

- `index.html`: portada con cuatro secciones y noticias cargadas desde `data/news.json` mediante AJAX.
- `galeria.html`: galería dinámica con filtros realizados en JavaScript.
- `presupuesto.html`: cálculo automático, extras por paquete y validación de los datos con JavaScript.
- `contacto.html`: datos de contacto, mapa de OpenStreetMap y cálculo de ruta.

## Carpetas

- `assets/css`: estilos de la web.
- `assets/js`: funciones JavaScript de cada página.
- `assets/img`: logotipo e imágenes del proyecto.
- `data`: archivo JSON utilizado por las noticias.

## Ejecución

El proyecto debe abrirse mediante un servidor local para que la carga AJAX y el mapa funcionen correctamente.
